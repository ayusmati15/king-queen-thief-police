# King - Queen - Thief - Police

A browser-based interactive role game inspired by logic and decision-making games.

## Description

Two players choose a role from **King, Queen, Thief, or Police**. The game evaluates choices based on **custom win rules** and announces the winner. The application supports **20+ interaction scenarios** without external APIs.

## Features

- Role-based logic handling **20+ matchups**
- Dynamic **winner announcement** with colored results
- Modular JavaScript functions for **real-time decision flow**
- Interactive **UI buttons** for player choices
- Responsive design using **CSS** with hover effects

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
